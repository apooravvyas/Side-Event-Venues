# SIDEQUEST — Where to host your side event in Mumbai

42 Mumbai venues, researched and scored for hosting Web3 and AI side events during
India Blockchain Week (1–2 Nov 2026, Fairmont Mumbai) and Devcon 8 (3–6 Nov, Jio World Centre).

Live: https://side-event-venues.vercel.app

## Design system

International Typographic Style (Swiss). Inter Tight for display, IBM Plex Mono for the
data layer, red (#e63329) as the only accent. Off-white poster landing → dark map product.
All tokens are in the first 30 lines of `css/styles.css`.

## Deploy

Static — no build step, no server. Push to `main` and Vercel redeploys.
Files: `index.html`, `css/`, `js/`, `data/`, `og.png`, `og.py`, `fonts/`.

If the domain changes, update the `og:url` / `og:image` / `twitter:image` tags in `index.html`.

## Venue photography

Three tiers, in order:

1. **Creative Commons** — 10 venues, 19 images, each verified by hand against that exact
   Mumbai location. Shipped in `venues.json` under `photos[]` with credit, licence and page link.
2. **Google Places Photos** — covers all 42, but needs an API key. Open `data/config.js`
   and follow the instructions at the top (5 minutes; free tier covers this traffic).
   Results cache in the visitor's browser for 30 days. A Places result is **rejected** if the
   returned place sits more than 2 km from our researched coordinates, so a same-name venue
   in another city can never be attached to the wrong entry.
3. **Typographic panel** — the fallback. No photo is ever invented or borrowed from a
   different branch of the same brand.

## Data

`data/venues.json` — one object per venue:

| field | meaning |
|---|---|
| `id`, `name`, `address`, `lat`, `lng` | identity and position |
| `cat` | hotel / restaurant / bar / rooftop / cafe / sports / creative / cowork |
| `area` | sahar / powai / santacruz / bkc / bandra / juhu / parel / east |
| `types` | mixer / party / dinner / workshop / hackathon / panel / builder / sports / creative / afterparty |
| `size.min`, `size.max`, `size.source` | headcount range; `published` or `estimated` |
| `scores` | 0–5 per factor, or `null` for unknown |
| `overall`, `known`, `confidence` | score, factors assessed, evidence strength |
| `tagline`, `summary`, `bestFor`, `formats.good/bad`, `facts` | editorial content |
| `evidence` | `{text, source}` — every claim carries one |
| `photos`, `placeQuery` | CC images; the string used for Places lookup |

`data/areas.json` — areas, event types, size bands, anchors, category list, and
`typeFactor` (which score factor decides each format).

Score rules: mean of ten factors ×2, unknowns counted as a neutral 3.0. Fewer than 8
factors assessed → displayed with a tilde. `confidence: high` requires published capacity,
a booking assessment and ≥3 evidence points.

## Deep links

- `?type=mixer&near=devcon&size=m` — a full brief (size: xs / s / m / l / xl)
- `?v=trident-bkc` — a venue; add brief params to get its verdict for your event
- `?cat=rooftop&area=parel`, `?q=padel`, `?sort=score` — refinements
